# Strona Janka

Prosta strona osobista zbudowana w HTML, CSS i JavaScript, hostowana na GitHub Pages.

## Pliki

| Plik | Zawartość |
|---|---|
| `index.html` | Strona startowa z zegarem warszawskim, przełącznikiem języka i zdjęciem. |
| `timer.html` | Timer z kolejką, gotowymi zestawami, dźwiękami, historią i trybem pełnoekranowym. |
| `style.css` | Wspólny wygląd strony i timera. |
| `i18n.js` | Teksty po polsku i angielsku oraz przełącznik języka. |
| `script.js` | Wspólny zegar warszawski i rok w stopce. |
| `timer.js` | Kolejka timerów, walidacja zakresu 1–10 sekund, zestawy, dźwięki i historia. |
| `fullscreen.js` | Obsługa trybu pełnoekranowego timera. |
| `assets/kensington.jpg` | Zdjęcie na stronie startowej. |

## Uruchomienie lokalne

Otwórz `index.html` w przeglądarce albo uruchom go przez Live Server w Visual Studio Code.

## Publikacja w GitHub Pages

Skopiuj całą zawartość folderu do repozytorium strony i wypchnij zmiany na skonfigurowaną gałąź Pages. Zachowaj folder `assets` i wszystkie pliki JavaScript obok plików HTML.

Czas timera można ustawić od 1 do 10 sekund. Gotowe zestawy również mieszczą się w tym zakresie.
